## 만들면서 추가로 고친 것

- **비밀 증강이 진행 기록으로 샜다.** `증강 획득: [B1c] …` 가 그대로 찍혀서, 온라인뿐 아니라
  AI 대전에서도 상대 비밀 증강이 기록만 읽으면 다 보였다. (원래 있던 결함)
- **예약 효과 tag / flags 키가 증강 id 그대로였다.** 목록만 가려서는 부족했다.
- **새로고침하면 내 가면 해독표가 날아갔다.** 서버에 보관된 판을 다시 받으면 내 비밀 증강을
  나조차 못 읽는 상태가 됐다 → sessionStorage 에 보관 (이 탭 밖으로 안 나간다).
- **`loadVault()` 직후 `startOnline()` 이 그 금고를 다시 비웠다.** 재접속 경로에서만 나던 버그.
- **`augCard` 가 모르는 증강 id 에 죽었다.** 화면 전체가 멈춰서 원인 파악이 늦어졌다 → 방어 코드.
- **메인 화면이 카드 3장을 감당 못 했다.** `1fr` 이 최소 너비에 밀려 141/134/309 로 제각각이 됐다
  → `repeat(auto-fit, minmax(252px, 1fr))`.
